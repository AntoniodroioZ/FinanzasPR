# v1.1 — Plan de implementación

**Estado:** implementado (agosto 2026).

## Objetivo

Contexto temporal en el dashboard: elegir mes, comparar con el anterior y ver los gastos individuales más grandes.

## Alcance

| # | Entrega | Criterio de hecho |
|---|---------|-------------------|
| A | **Selector de mes** | Nav global (‹ › + input month); aplica a dashboard, movimientos y liquidación |
| B | **Vs mes anterior (Δ%)** | Deltas en ingresos, gastos, balance neto y tasa de ahorro |
| C | **Top gastos del mes** | Tabla con fecha, descripción, categoría, tu parte y % del gasto |

## Fuera de alcance

- Burn rate / proyección fin de mes
- Tendencias multi-mes (6 meses)
- Filtros avanzados en movimientos
- Presupuestos

## Archivos

- `js/transactions.js` — helpers de mes (`shiftMonth`, `monthToInputValue`, …)
- `js/analytics.js` — `formatMonthDelta`, `computeTopExpenses`
- `js/app.js` — `state.selectedMonth`, fetch mes N-1, month nav, renders
- `index.html` — barra de mes, deltas en KPIs, tabla top gastos
- `css/styles.css` — month nav, data-table, card-delta
