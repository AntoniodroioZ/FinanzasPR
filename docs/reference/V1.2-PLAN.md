# v1.2 — Plan de implementación

**Estado:** implementado (v1.2).

## Objetivo

Pasar de **observar** el gasto a **controlarlo con límites conscientes**: presupuestos por categoría, avisos calmados al acercarse al tope, y contexto de cuánto queda por bucket 50/30/20.

El usuario debe poder responder: *“¿Voy bien en Alimentación este mes?”* sin abrir la calculadora.

## Modelo de datos

### Nueva tabla: `category_budgets`

```sql
CREATE TABLE public.category_budgets (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  group_id UUID NOT NULL REFERENCES public.groups(id) ON DELETE CASCADE,
  category_id UUID NOT NULL REFERENCES public.categories(id) ON DELETE CASCADE,
  -- Primer día del mes al que aplica (YYYY-MM-01)
  month DATE NOT NULL,
  amount NUMERIC(12, 2) NOT NULL CHECK (amount > 0),
  created_by UUID REFERENCES auth.users(id) ON DELETE SET NULL,
  created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
  UNIQUE (group_id, category_id, month)
);

CREATE INDEX idx_category_budgets_group_month
  ON public.category_budgets(group_id, month);
```

**Reglas de negocio**

- Solo categorías `type = 'gasto'`.
- Un presupuesto por categoría por mes por grupo.
- **Copiar del mes anterior**: acción UX para pre-rellenar presupuestos (no automático silencioso).
- El gasto consumido usa la misma regla que `userGastoAmount` en `analytics.js` (personal + parte compartida).
- Mes sin presupuesto definido → categoría sin barra de límite (comportamiento actual).

### RLS (resumen)

- `SELECT / INSERT / UPDATE / DELETE`: miembros del `group_id` (`is_group_member`).
- `INSERT`: `created_by = auth.uid()`.

### Nueva vista: `#presupuestos`

Acceso: bottom-nav (5º ítem) o enlace desde dashboard.

```
Presupuestos — Agosto 2026
[Copiar del mes anterior]

| Categoría      | Presupuesto | Gastado | Acción   |
| Alimentación   | [ 500.00 ]  | $420    | Guardar  |
| Restaurantes   | [ 150.00 ]  | $180    | ⚠        |

```

- Input numérico por fila; categorías de gasto del grupo ordenadas por nombre.
- Empty state: “Define límites opcionales — sin presión, solo claridad.”

### Alertas (tono calmado)

- **Dashboard**: chips en categorías sobrepasadas; no modales intrusivos.
- **Tip del asesor** (`tips.js`): priorizar tip de presupuesto si hay categoría ≥100%.
- **Toasts**: solo al guardar presupuesto o al cruzar 100% en sesión activa (debounce, 1 por categoría por sesión).

Copy ejemplo: *“Restaurantes superó tu presupuesto este mes. Un ajuste pequeño el resto del mes puede equilibrar.”*
